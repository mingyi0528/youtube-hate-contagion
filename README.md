# Reproducibility Materials for Thesis

This repository contains reproducibility materials for the thesis

## Contents

- `codebook/` : coding rules and LLM classification prompts for incivility and intolerance
- `code/` : shared analysis modules (data loading, variable construction, model specifications)

## Data availability

Raw YouTube comment text, author-identifying information, comment IDs, and the full comment-level labeled dataset are not publicly redistributed, in accordance with research ethics and privacy considerations. This repository provides the codebook, LLM classification prompts, and the analysis modules for transparency and reproducibility.
